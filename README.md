# 作家助手拼字房

在 MaiBot 中查询作家助手拼字房的房间号、邀请链接和成员字数榜单，支持管理员私聊扫码授权，默认由模型判断调用房间工具，无房时按配置自动建房并分享邀请。插件使用安装者自己的作家助手账号，不需要向插件作者提供账号、密码或登录凭据。

## 环境要求

- MaiBot **1.3.9 起的 1.3 系列**、宿主提供的 maibot-plugin-sdk **2.14.0 起的 2.x 系列**。插件清单允许该范围内后续版本尝试加载；实际验证基线为 MaiBot **1.3.9 / SDK 2.14.0**，不代表所有后续版本均已测试。MaiBot 1.4 或 SDK 3.x 暂不纳入范围。
- SDK 由 MaiBot 宿主管理，插件依赖安装不会强制安装或降级宿主 SDK。
- Python **3.12 或更高**，可正常发送私聊文本和图片的 QQ 适配器。
- Playwright 与 Chromium。运行环境须能访问 QQ 登录页面和阅文服务。

当前版本为预发布版本。登录和房间接口依赖第三方服务，服务变更可能导致功能暂时不可用。

## 安装

从本仓库 Releases 下载插件 ZIP，在 MaiBot WebUI 的插件管理中选择从 ZIP 安装，然后按宿主提示重启或加载插件。也可将插件文件放入 MaiBot 的 `plugins/zuojia-room/` 目录；该目录内应直接包含 `_manifest.json` 和 `plugin.py`，避免多套一层目录。

在**运行 MaiBot 的同一 Python 环境**中安装依赖：

```bash
python -m pip install -r plugins/zuojia-room/requirements.txt
python -m playwright install chromium
```

上面的目录以手动安装为例；WebUI 安装时请替换为实际安装目录。使用 uv 管理 MaiBot 环境时，可将命令中的 `python` 替换为 `uv run python`。Linux 首次准备浏览器系统依赖时，可使用 `python -m playwright install --with-deps chromium`；安装系统依赖可能需要系统管理员权限。

Chromium 需要提前安装，插件不会在运行时自动下载浏览器。完成依赖安装后，在 WebUI 插件配置中启用插件并设置访问范围。配置由宿主生成，不需要从其他安装者复制配置文件。

## 首次配置

| 配置项 | 用途与默认行为 |
| --- | --- |
| `plugin.enabled` | 插件总开关，默认开启。 |
| `admin_user_ids` | 可私聊扫码授权的管理员 QQ 号。默认空，不允许任何人扫码；建房权限选 `admins` 时也用于限定建房。 |
| `group_whitelist` | 允许查询的群号。默认空，不响应任何群。 |
| `private_chat_enabled` | 是否允许私聊查询，默认开启。 |
| `private_user_ids` | 允许私聊查询的 QQ 号。默认空，表示允许所有私聊用户查询；仅供自己使用时请填入自己的 QQ 号。 |
| `create_room_if_missing` | 查询邀请时无有效房间则自动创建，默认开启。 |
| `room_data_create_if_missing` | 查询榜单时无有效房间则创建并发邀请，默认开启；刚发邀请后的抑制窗口内不重复创建。 |
| `room_creation_permission` | 默认 `allowed_chats`，已开放聊天中的成员可触发建房；改为 `admins` 可限制为管理员。与扫码授权权限独立。 |
| `trigger_modes` | 可启用 `command`、`keyword`、`tool` 入口。 |
| `keyword_reply_mode` | 默认 `llm_first`：先让模型判断并调用房间工具，约 20 秒没有出站回复时插件兜底；`always` 为直接回复；`tool_only` 仅靠模型工具。 |

建议先只开放管理员私聊，确认授权与查询正常后，再添加需要响应的群。QQ群号和用户 QQ 号均在本机 WebUI 中填写，不要提交到公开仓库。默认已开放聊天中的成员可以触发自动建房，私聊名单为空时包括所有私聊用户；请先设置访问范围，再完成授权。默认房间为 60 分钟、30000 字、50 人。从旧配置升级时，请在 WebUI 检查 `keyword_reply_mode=llm_first`、`create_room_if_missing=true`、`room_data_create_if_missing=true`、`room_creation_permission=allowed_chats`；已有配置不会被升级覆盖。若只允许管理员建房，保留 `room_creation_permission=admins`。其他选项及其默认值可在 WebUI 配置说明中查看。

### 房间参数与触发控制

房间请求固定访问阅文官方服务，不支持自定义 API 主机。旧字段 `api_base_url` 仅兼容保留并在 WebUI 隐藏：其值不用于请求地址，留空仍会禁用房间查询，请保持默认值。

以下是 WebUI 配置字段，不是在 QQ 消息中追加的命令参数。列表字段填写多个值，布尔字段使用开关，时间字段注意单位。

| 字段 | 类型 / 默认值 | 含义与填写方式 |
| --- | --- | --- |
| `room_default_duration_minutes` | 整数 / `60` | 新房间持续时间，单位分钟。 |
| `room_default_word_goal` | 整数 / `30000` | 新房间目标字数，单位字。 |
| `room_default_member_limit` | 整数 / `50` | 新房间人数上限。 |
| `room_data_rank_limit` | 整数 / `13` | 榜单最多展示人数。 |
| `fallback_delay_seconds` | 数值 / `20` | `llm_first` 等待模型出站回复的秒数，超时才兜底。 |
| `keyword_cooldown_seconds` | 数值 / `120` | 同一会话关键词回复冷却秒数；`0` 关闭。 |
| `reply_dedup_seconds` | 数值 / `10` | 同一会话相同文本去重窗口秒数；`0` 关闭。 |
| `room_data_suppress_after_link_seconds` | 数值 / `120` | 发邀请后，榜单工具在窗口内不因无房再次建房；`0` 关闭。 |
| `keywords` | 字符串列表 / `有房吗`、`码字房`、`拼字房` | 任一子串命中即进入关键词处理；可自行调整。 |
| `keyword_patterns` | 字符串列表 / 空 | 可选Python正则，与关键词子串任一命中即可触发。 |
| `keyword_failure_llm_reply` | 布尔 / `true` | 群内普通成员查询失败时是否用宿主模型润色提示；数据范围见下文隐私说明。 |

例如，要创建30分钟、目标5000字、最多20人的房间，在 WebUI 分别将时长、字数、人数设为 `30`、`5000`、`20`，保存后使用 `/拼字房`。这些参数只用于后续新建房间，不修改已经存在的房间。

## 扫码授权

1. 已配置的管理员向机器人私聊发送 `/拼字登录`，阅读返回的官方协议。
2. 同意后发送 `/拼字登录确认`，等待机器人在本私聊发送二维码。
3. 使用绑定作家助手的 QQ 扫码并在手机上确认。机器人提示授权成功后，即可查询房间。

二维码短时有效，过期后需重新发起；使用 `/拼字取消登录` 可终止当前扫码。二维码只发送给发起授权的管理员。插件不要求用户提供密码、Cookie 或票据。

授权涉及阅文官方协议：[用户服务协议](https://activity.write.qq.com/noah/202211071)、[隐私政策](https://activity.write.qq.com/noah/202211072)、[作品合作基础协议](https://activity.write.qq.com/noah/142855555)。请在授权前自行阅读并确认是否接受。

## 使用方式

日常使用 `/拼字房` 获取邀请，`/拼字榜单` 查看榜单。所有命令使用“拼字”前缀，不注册旧命令或兼容别名。

| 命令 | 功能 | 权限与位置 |
| --- | --- | --- |
| `/拼字房` | 查询有效房间；无房时按配置创建并发邀请。 | 已开放群或私聊，建房受独立策略限制。 |
| `/拼字榜单` | 查询成员榜单；无房时按配置建房并发邀请。 | 已开放群或私聊。 |
| `/拼字登录` | 展示协议，不立即发二维码。 | 管理员私聊。 |
| `/拼字登录确认` | 同意此前协议并发起扫码，确认有效期10分钟。 | 同一管理员、同一私聊。 |
| `/拼字取消登录` | 清除待确认并取消当前扫码。 | 管理员私聊。 |
| `/拼字授权状态` | 查看授权状态，不回传凭据。 | 管理员私聊。 |

### 命令参数

上述命令均不接受参数。房间时长、字数、人数在 WebUI 配置；不再使用 `auth` 参数。

### 使用示例

- 管理员首次授权：私聊发送 `/拼字登录`，阅读协议后发送 `/拼字登录确认`，再扫码确认。
- 群成员获取邀请：在已开放的群发送 `/拼字房`；授权有效且无房时，默认创建房间并分享邀请。
- 查看榜单：发送 `/拼字榜单`，无需额外参数。
- 排查授权：管理员私聊发送 `/拼字授权状态`，无需重新扫码。

例如，在已开放的私聊或群中发送 `/拼字房`，机器人会返回当前有效房间的邀请信息。授权有效但无房间时，默认按配置自动建房并分享邀请；未授权时提示管理员登录，不会绕过授权。也可直接询问“有码字房吗”，让模型调用工具。工具发出邀请后提示模型不要重复回复。不需要自动建房时请同时关闭两个建房开关。

关键词与模型工具同样受聊天访问范围限制。`keyword_failure_llm_reply` 默认开启：群内普通成员触发关键词但查询失败时，插件会把该条消息的前 100 个字符和基础提示文案交给宿主配置的模型服务润色。若不希望此行为，请在 WebUI 将该项关闭；关闭后使用固定提示文案。默认关键词为“有房吗、码字房、拼字房”，不使用宽泛的“房间”作为关键词；模型工具仍可理解相关自然语言。关键词可以在 WebUI 中调整，冷却和出站去重选项可减少重复回复。模型工具需要宿主已配置可用模型；普通房间命令不要求模型生成回复。

也可使用 `manual_room_number` 和 `manual_room_link` 手动维护邀请信息。手动模式不会提供实时成员榜单。

## 注意事项与隐私

授权状态保存在宿主分配的插件数据目录，用于恢复会话、查询房间和主动续期。只有新授权通过业务验证后才替换已保存状态；失败保留旧文件。Linux 授权文件以仅当前用户可读写的权限保存。Windows 下应由安装者为插件数据目录配置仅运行账户可访问的 ACL；不要仅依赖 `chmod`。

插件还会在数据目录保存用于防止重复回复的短期记录，包含会话标识、回复文本及其中的房间邀请链接。Linux 下该缓存同样限制为仅当前用户可读写；Windows 下请对整个插件数据目录配置访问控制。不要公开上传该目录。

请将授权文件视为账号凭据，不要上传到 GitHub、网盘公开链接或问题反馈附件中。备份时同样需要保护授权数据。分享日志前，请删除用户和群标识、二维码、Cookie、票据及其他敏感信息。

房间邀请链接和成员榜单会发往允许访问的聊天，请按实际使用范围设置白名单。插件通过 QQ 和阅文服务处理授权及房间请求；使用模型工具或默认开启的关键词失败润色时，还会使用宿主配置的模型服务；可关闭 `keyword_failure_llm_reply` 停止失败润色。插件不需要作者提供的中转服务器。

授权可能被第三方服务撤销或过期，主动续期不保证永久有效。遇到授权失效提示，请由管理员重新扫码。Windows 正式授权存储的完整访问控制和真实到期后的自动续期尚未完成验收。

## 常见问题

- **不回复群消息**：检查群白名单、插件开关和入口配置，并确认 QQ 适配器正常。群白名单为空时不会响应群。
- **无法生成二维码**：确认 Playwright、Chromium 及系统依赖安装在宿主使用的环境中，并检查登录页面能否访问。
- **二维码没有收到**：检查管理员名单、是否为私聊，以及适配器是否支持发图；不要在群里发起授权。
- **没有实时榜单**：确认账号授权有效且存在有效房间；手动房间模式不支持榜单。
